# Genotype information

A PCA matrix of rice genotype information. This data was published by
Zhao et al. (2011) \<doi:10.1038/ncomms1467\>

## Usage

``` r
geno
```

## Format

A numeric matrix (PCA) with 404 rows (sample) and 404 columns (PCs).

## Source

<http://www.ricediversity.org/data/>

## Examples

``` r
data(geno)
```
